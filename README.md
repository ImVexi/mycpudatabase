# CPUDb

A fast, searchable database for browsing and comparing CPU and GPU specs — built with vanilla JavaScript and styled with a dark, PCB-inspired aesthetic.

## Features
- Browse a full catalog of CPUs and GPUs pulled from `all_cpus.json` / `all_gpus.json`
- Clean, dark-themed UI designed to feel like you're looking at a circuit board
- Deployed via Cloudflare Workers (`wrangler.jsonc`) for fast, edge-hosted access
- Lightweight — no heavy frameworks, just HTML/CSS/JS

## Tech Stack
- JavaScript, HTML, CSS
- Cloudflare Workers for hosting/edge functions
